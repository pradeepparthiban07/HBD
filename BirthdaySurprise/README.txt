BIRTHDAY SURPRISE WEBSITE
=========================

Files
-----
- index.html  : Page structure
- style.css   : Responsive styling and animations
- script.js   : Interactions and personalization
- images/     : Add your own photos here

Run locally
-----------
1. Extract this ZIP file.
2. Open the BirthdaySurprise folder in Visual Studio Code.
3. Open index.html in a browser (or use the Live Server extension).

Personalize
-----------
Open script.js and edit:

const birthdayGirl = "Birthday Girl";
const birthdayDate = "";

Use a date in YYYY-MM-DD format, for example:
const birthdayDate = "2026-11-15";

Add photos
----------
Place four images in the images folder with these names:
photo1.jpg
photo2.jpg
photo3.jpg
photo4.jpg

You can change filenames and captions in the `photos` array in script.js.

Notes
-----
- The countdown uses the visitor's device local time.
- Google Fonts requires an internet connection; fallback fonts are provided.
- The website is static and does not collect or send personal data.
